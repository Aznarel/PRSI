    Reto colaborativo¶

    🏆 PO5.14 Reto colaborativo: Rent a car¶

    (C.ESP1 / CE1.1, CE1.2 / IC4-30p)

    Imaginad que perteneceis al departamento técnico de una empresa que ha ganado una licitación sobre para el diseño de una base de datos de una empresa de alquiler de coches.

    Nos piden crear una base de datos denominada RENT A CAR que constará de tres tablas:

    • Flota, donde se controlan los coches existentes
    • Distribuidor (servicio técnico)
    • Alquileres

    Pasos a realizar¶

    1. Abre LibreOffice - Base y crea la base de datos BBDD_RENTaCAR
    2. Crea las tres tablas con la estructura pedida.
    3. Las claves primarias deberán ser seleccionadas por el alumno, siendo las más apropiadas en cada caso, y se deberán realizar las relaciones correctamente.
    4. Rellena la tabla con los datos de ejemplo proporcionados.

    5. Crear tres consulta:

      • Usa el asistente con una única tabla.
      • Usa combinación de asistente y modo diseño empleando varias tablas.
      • Usa únicamente modo diseño empleando varias tablas.
      Ejemplo de posibles consultas
      1. Listar todos los coches españoles
      2. Listar los distribuidores ordenados alfabéticamente por ciudad
      3. Mostrar los alquileres con los datos del coche alquilado
      4. Ver los alquileres realizados a través de distribuidores de Madrid
      5. Calcular cuántas veces ha sido alquilado cada coche
      6. Mostrar todos los coches comprados a partir del año 2020

    6. Crea dos formulario.

      • Usa el asistente con una única tabla.
      • Usa únicamente modo diseño empleando varias tablas.

    7. Crea dos informes.

      • Usa el asistente con una única tabla.
      • Usa únicamente modo diseño empleando varias tablas.

    Entregable¶

    Fichero .zip identificado con el nombres y apellidos de los alumnos/as que forman el grupo y que contenga:

    1. La base de datos BBDD_RENTaCAR.
    2. Entrega en un Writer con una capturas de pantalla donde se demuestre los pasos para la realización de cada punto del ejercicio.
